# UTM Builder

A React + Vite app for creating and managing UTM-tagged campaign URLs, with all data stored locally in the browser via Dexie (IndexedDB).

## Agent skills

### Issue tracker

Issues live in GitHub Issues on `cdkisa/UtmBuilder`, driven by the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, each using its default label string. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and one `docs/adr/` at the repo root. See `docs/agents/domain.md`.
